- Frame limiter configuration presets for reduced latency and stable frame pacing
- Per-application profile templates for automatic overlay switching
- Benchmarking and logging workflow guides with export examples
- Scanline sync and sync limiter documentation for tear-free gaming
- Integration examples with MSI Afterburner and HWiNFO
- Step-by-step tutorials covering hotkeys, OSD toggling and profile backup

## Requirements

- Windows 10/11
- Installed RivaTuner Statistics Server (RTSS)

## Usage

Open the extracted folder and explore the profile and guide directories. Import the included `.cfg` profiles directly into RTSS or follow the documentation to configure OSD layouts, frame limiter values, scanline sync, and per-application rules. The guides provide practical instructions for each resource.
